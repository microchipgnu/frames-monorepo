Permissionless tool registry

Anyone can register a service on-chain. Agents discover via program state — no curation, no gatekeeper.

Why OATP uses gRPC from OOBE Synapse — and why we pay for the Advanced tier

Agents do not wait. We run a hybrid of JSON-RPC + gRPC streaming on OOBE Synapse because under sustained agent load neither protocol alone is enough — and we pay for the Advanced tier because what we're buying isn't bandwidth: it's consistency under load, submit priority, and the fact that gRPC streaming is bundled into Advanced rather than sold as a separate add-on.
