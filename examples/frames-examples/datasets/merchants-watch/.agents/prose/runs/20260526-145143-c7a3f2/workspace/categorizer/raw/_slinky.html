FAQ

Frequently Asked Questions

How do I list my API?

You simply provide an endpoint and set a price. SlinkyLayer automatically wraps it in a pay-per-call interface and makes it discoverable to agents and applications.

How do payouts work?

Every call to your API triggers an on-chain micropayment on Coinbase's Base network or BNB Chain. You receive 95% instantly to your wallet - no minimums, delays, or custodians.

What does SlinkyLayer charge?

We take a 5% commission on each request. There are no setup fees, subscription costs, or lock-ins.

How is trust/reputation handled?

Each call can be rated. Ratings are published via ERC-8004, enabling a portable, verifiable reputation that other platforms and agents can use for discovery.

Can agents use my API automatically?

Yes. The platform supports machine-safe authentication and payments, enabling autonomous agents to consume your API without human intervention - ideal for the M2M economy. The protocol and interface were developed by Coinbase and co-developed in partnership with Cloudflare, with ecosystem support from major web infrastructure providers.
