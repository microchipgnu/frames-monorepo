[HYRE] AGENT

Pay-per-call DeFi intelligence for autonomous agents. 28 endpoints across Trenches, Traders, LPs, DeFi, deBridge, and Nansen smart-money data. Multi-chain x402 on Solana, Base, SKALE + MPP on Tempo. No API keys — payment is the only gate.

Payment Rails

Solana x402 (root paths) — PayAI facilitator (sponsored gas)
Base x402 /base/* — PayAI facilitator
SKALE x402 /skale/* — PayAI (zero gas)
Tempo MPP /mpp/* — Solana fee sponsorship

Endpoints

  • Trenches — new tokens, bonding curves, sniper/verdict
  • Traders — wallet PnL, top wallets, whales, OHLCV
  • LPs — Meteora pool list, recommend, strategy
  • DeFi — TVL, yields (DeFiLlama + Jupiter)
  • deBridge — cross-chain quote + yield migration
  • Nansen — smart money screener, flow-intel, wallet-intel
  • Ask — natural language DeFi query (LLM cascade)
