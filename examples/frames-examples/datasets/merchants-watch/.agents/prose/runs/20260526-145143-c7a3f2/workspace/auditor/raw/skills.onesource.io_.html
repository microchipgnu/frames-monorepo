OneSource

Pay-per-call Ethereum RPC for AI agents.

Every endpoint proxies a single live RPC call - balances, blocks, receipts, events, ENS, contract and NFT introspection - returning fresh data from Ethereum mainnet. No API keys, no accounts. Pay per request: USDC on Base via x402, or pathUSD or USDC.e on Tempo via MPP.

Discover

  • /openapi.json - full OpenAPI 3.1 spec with per-endpoint pricing, input/output schemas, and x-bazaar discovery metadata
  • /.well-known/x402 - x402 discovery fallback document
  • /api/pricing - flat list of endpoints and per-call USDC cost
  • /api/networks - supported networks (ethereum, sepolia, avax)

Try it

Using AgentCash (handles both x402 and MPP):

npx agentcash try https://skills.onesource.io

Or call directly with @x402/fetch for x402, or mpp-go for MPP - either client handles the 402 payment flow automatically.
